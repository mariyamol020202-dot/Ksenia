Через формы сайта пользователь может добровольно передать имя, роль или статус обращения, возраст ребёнка, интересующий формат обучения, номер телефона, адрес электронной почты и текст комментария.

4. Основание и срок обработки

Данные обрабатываются на основании добровольного согласия пользователя, которое выражается при заполнении формы и установке отметки о согласии с настоящей политикой.

Данные хранятся не дольше, чем это необходимо для цели обращения, либо до отзыва согласия пользователем, если иной срок не требуется по закону.

Персональные данные не продаются и не передаются третьим лицам для самостоятельного маркетинга. Для технической доставки заявок используется сервис FormSubmit. При отправке формы данные передаются этому сервису только для доставки обращения на электронную почту владельца сайта.

Текущая версия сайта не использует рекламные cookie. Технические сервисы, подключённые к форме отправки, могут применять необходимые механизмы для безопасности и доставки обращения. Если в будущем будет подключена дополнительная веб-аналитика, политика будет обновлена с учётом фактически используемых сервисов.

8. Защита данных

Владелец сайта принимает разумные организационные и технические меры для защиты полученных данных от неправомерного доступа, изменения, раскрытия или уничтожения. Доступ к заявкам предоставляется только в объёме, необходимом для обработки обращения.

Пользователь вправе запросить уточнение или удаление своих данных, а также отозвать согласие на их обработку. Для этого можно направить обращение через форму обратной связи на сайте либо написать на mandarinka.chinese88@gmail.com, указав контакт, который использовался при отправке заявки.
