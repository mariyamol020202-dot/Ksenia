# Лендинг Ксении Максимовны

Готовая статическая первая версия для GitHub Pages.

## Быстрый запуск
1. Загрузите содержимое этой папки в репозиторий GitHub.
2. Включите GitHub Pages: Settings → Pages → Deploy from branch → main / root.
3. Откройте выданную GitHub ссылку.

## Что заменить перед публикацией
- `assets/hero-placeholder.svg` → профессиональная фотография Ксении Максимовны. Можно сохранить новое фото под тем же именем либо поменять путь в `index.html`.
- `assets/china-placeholder.svg` → фото из поездки в Китай.
- Ссылку Telegram в блоке контактов.
- Заглушки отзывов на реальные отзывы.
- При наличии согласования — добавить фото/имя Валерии Мещеряковой в блок проекта.
- Подключить реальную отправку форм. Сейчас формы показывают успешное сообщение, но данные никуда не отправляют.
- Дополнить `privacy.html` фактическими данными оператора и используемыми сервисами.

## Формы
Для GitHub Pages нужен внешний сервис, например Formspree/Netlify Forms (при переносе на Netlify), либо собственный Telegram-бот/CRM webhook. После выбора сервиса форму можно подключить без изменения дизайна.

## Редактирование без кода
Текущая версия — статическая. Для полноценного редактирования без кода можно следующим шагом подключить Decap CMS или перенести макет в конструктор/CMS. Дизайн и структура уже готовы.
