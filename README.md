# Лендинг Ксении Максимовны

## Фотографии
Положите свои JPG-файлы в папку `assets` с теми же именами, заменив текущие изображения:

- `hero.jpg` — главное фото Ксении
- `kseniya-about.jpg` — фото в блоке «Обо мне»
- `project.jpg` — фото проекта / совместной работы
- `certificate-1.jpg`, `certificate-2.jpg` — сертификаты или результаты учеников
- `china-1.jpg` ... `china-4.jpg` — фотографии поездки в Китай

Раздел с отзывами в первой версии скрыт, чтобы на опубликованном сайте не было фиктивного контента. Его можно вернуть после появления реальных отзывов.

## Формы
Сайт подготовлен для отправки заявок на e-mail через FormSubmit без отдельного сервера.

Файл `assets/site-config.js` содержит две настройки:

```js
window.SITE_CONFIG = {
  formEmail: "",
  telegramUrl: ""
};
```

В `formEmail` нужно вписать e-mail Ксении. После первой тестовой отправки FormSubmit пришлёт на этот адрес письмо для подтверждения. После подтверждения заявки будут приходить на почту.

`telegramUrl` необязателен. Если указать ссылку вида `https://t.me/username`, на сайте автоматически появится кнопка Telegram.

## Публикация
Для GitHub Pages достаточно загрузить содержимое папки в корень репозитория. Главная страница — `index.html`, политика конфиденциальности — `privacy.html`.
