## Заявки на почту
Ничего регистрировать заранее не нужно. В обе формы уже встроена отправка через FormSubmit на:

`mandarinka.chinese88@gmail.com`

После загрузки сайта на GitHub Pages:

1. Откройте опубликованный сайт.
2. Отправьте первую тестовую заявку.
3. На `mandarinka.chinese88@gmail.com` придёт письмо от FormSubmit с просьбой подтвердить адрес.
4. Нажмите кнопку/ссылку подтверждения в письме.
5. Отправьте вторую тестовую заявку — она должна прийти на эту почту как обычное письмо.

FormSubmit не требует регистрации аккаунта. После подтверждения адреса сервис может прислать защищённый токен вместо открытого e-mail — его можно подключить позднее, но для запуска это необязательно.

## Политика конфиденциальности
Страница находится в `privacy.html`; ссылки на неё уже стоят рядом с согласием в формах и в подвале сайта.

## Публикация
Загрузите содержимое этой папки в корень репозитория GitHub Pages. Главная страница — `index.html`. После обновления файлов дождитесь публикации GitHub Pages и сделайте тест формы уже с опубликованного сайта.
